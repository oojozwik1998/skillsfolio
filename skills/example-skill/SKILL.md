# Example skill

This file shows the format every skill in this catalog follows.

## When to use

Use it as a starting point when adding a new skill.

## Steps

1. Create a folder in `skills/` with the skill name.
2. Add a `SKILL.md` file with `name` and `description` at the top.
3. Write the instructions below them.
